# AI Setup

A ready-made AI workspace for Windows: Claude Code with an AI team (Claude, GPT/Codex, Gemini, Grok, local models), a project launcher (Claude Agent), the Pico Command Bridge, rules, skills and flows - set up in one run.

## Install

1. Download the newest **AISetup_user-X.Y.Z.zip** from [Releases](https://github.com/CalvinJonker/AI-Developer/releases/latest).
2. Right-click it > Properties > Unblock, then Extract All.
3. Run **DEPLOY.cmd** in the extracted folder.

Updates: Claude Agent menu > **U**. Every release is signed; an install only accepts releases signed by the maker.
